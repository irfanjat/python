# Python Practice

A collection of Python scripts covering fundamentals — data types, conditionals, operators, input handling, and basic algorithms. Built while learning core Python programming concepts.

## Scripts

| File | Description |
|------|-------------|
| `hello.py` | Basic print and string output |
| `variables.py` | Variable declaration and assignment |
| `dataTypes.py` | Working with int, float, string, bool |
| `input.py` | User input handling |
| `ArithmeticOpe.py` | Arithmetic operations |
| `logicalOperator.py` | Logical operators and comparisons |
| `coditions.py` | If/else conditional logic |

## Run

```bash
python3 hello.py
```
